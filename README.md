\## 🇬🇧 English



A high-efficiency sidechain ducking and dynamic frequency control system built for REAPER 7. It includes both reusable Track Templates (`.RTrackTemplate`) and a standardized Project Template (`.RPP`).



\### 📌 Features

\- \*\*Pre-configured Routing\*\*: Built-in 3/4 auxiliary bus mapping, eliminating manual multi-channel audio stream routing.

\- \*\*Dynamic Frequency Response\*\*: Optimized for low-end conflict management (Kick/Bass masking) and spatial clearing to maintain mix clarity.

\- \*\*Modular \& Reusable\*\*:

&#x20; - `.RTrackTemplate`: Instant one-click import into any existing mixing session.

&#x20; - `.RPP`: Provides a standardized starting setup for new projects.



\### 📁 Included Files

\- `Sidechain\_Ducking.RTrackTemplate` - Track template with full routing and plugin chains pre-configured.

\- `Main\_Mix\_Template.RPP` - REAPER project template with sidechain architecture and basic bus planning.



\### 🚀 Usage



\#### 1. Importing Track Templates

1\. Download the `.RTrackTemplate` file and place it into REAPER's `TrackTemplates` directory:

&#x20;  > `Options` -> `Show REAPER resource path in explorer/finder...` -> `TrackTemplates`

2\. Right-click on the track panel in REAPER: `Insert track from template` -> Select this template.



\#### 2. Project Template Setup

1\. Download the `.RPP` file and place it into the `ProjectTemplates` directory.

2\. Go to REAPER Settings: `Preferences` -> `Project` -> Select the `.RPP` file in `When creating new project, use project file as template`.



\### 🛠️ Requirements

\- \*\*DAW\*\*: REAPER v7.0 or higher

\- \*\*Plugins\*\*: REAPER native plugins (ReaComp / ReaXcomp)

\## 🇨🇳 中文



一个专为 REAPER 7 打造的高效侧链闪避（Sidechain Ducking）与频段动态控制模板系统，包含可复用的轨道模板（Track Template）与预设工程模板（Project Template）。



\### 📌 项目特性

\- \*\*预置通道路由 (Pre-configured Routing)\*\*：内置 3/4 辅助总线映射，无需重复手动配置多通道音频流。

\- \*\*动态频段响应 (Dynamic Processing)\*\*：针对低频挤占（Kick/Bass 遮蔽）与空间挤压进行优化，提供干净自然的闪避效果。

\- \*\*开箱即用与高复用性 (Modular \& Reusable)\*\*：

&#x20; - `.RTrackTemplate`：支持在任意现成混音工程中一键拉入。

&#x20; - `.RPP`：提供标准化的全新工程起点。



\### 📁 文件说明

\- `Sidechain\_Ducking.RTrackTemplate` - 包含完整路由与插件链的侧链轨道模板

\- `Main\_Mix\_Template.RPP` - 包含侧链架构与基础总线规划的 REAPER 工程模板



\### 🚀 使用方法



\#### 1. 轨道模板导入

1\. 下载 `.RTrackTemplate` 文件并将其放入 REAPER 的 `TrackTemplates` 目录下：

&#x20;  > `选项 (Options)` -> `显示 REAPER 资源路径 (Show REAPER resource path...)` -> `TrackTemplates`

2\. 在 REAPER 轨道面板空白处右键：`从模板插入轨道 (Insert track from template)` -> 选择本模板。



\#### 2. 工程模板设置

1\. 下载 `.RPP` 文件放入 `ProjectTemplates` 目录下。

2\. 打开 REAPER 设置：`首选项 (Preferences)` -> `工程 (Project)` -> 在 `新建工程时使用模板文件` 中选中该 `.RPP` 文件。



\### 🛠️ 环境要求

\- \*\*DAW\*\*: REAPER v7.0 或更高版本

\- \*\*插件\*\*: REAPER 原生插件 (ReaComp / ReaXcomp)
